# VACANCY SQL PROJECT
Проект представляет из себя мини-приложение которое способно получить работодателей и их вакансии с помощью API headhunter
(Это ответвление от прошлого проекта под названием SEARCH_VACANCY_PROJECT)
## Содержание
В проекте содержится 5 функциональных и 5 тестовых модуля находящиеся в пакетах src and tests соответсвенно

## Использование

c помошью команды pip freeze > requirements.txt вы можете посмотреть зависимости проектак тому же желательно использовать окружение poetry для удобного отображения информации о зависимостях, для того чтобы запустить проект воспользуйтесь командой python3 main.py и для успешного выполнения следуйте указанным инструкциям
